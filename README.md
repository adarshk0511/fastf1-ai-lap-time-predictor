# FastF1 AI Lap Time Predictor

A simple machine learning project using FastF1 and Scikit-Learn.

## Features

- Loads Formula 1 race data using FastF1
- Cleans lap data using Pandas
- Trains a Random Forest Regressor
- Predicts lap times
- Visualizes feature importance

## Tech Stack

- Python
- FastF1
- Pandas
- Scikit-Learn
- Matplotlib
- Jupyter Notebook
